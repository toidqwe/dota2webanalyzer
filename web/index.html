Кто виноват

Индекс вины 0–100 и доля ответственности для каждого игрока проигравшей команды. Не «глазами», а по экономике, смертям, дракам и вижну.

Переломные моменты

Модель шансов по минутам находит драки, Рошанов и объекты, которые реально перевернули игру — с падением вероятности в процентных пунктах.

Цена ошибки

Каждая смерть оценена в золоте: потерянный фарм, отданный баунти и время вне игры. Ошибки сгруппированы по игрокам и severity.

Полная статистика

Лейнинг, нетворс, урон, драки, вижн, предметы, байбеки, аегис, сравнение с визави и командные бары — всё в одном отчёте.

Как это работает

  1. 01
    ID матча

    Берём распарсенный реплей: поминутные графики, смерти, драки, объекты, покупки.

  2. 02
    Модель

    Считаем ролевые нормы, цену смертей, вероятность победы и шесть категорий оценки для каждого героя.

  3. 03
    Отчёт

    Собираем вердикт: виновники, заслуги, ошибки с таймингами и главный переломный момент.

Что проверить
  • ID матча — только цифры, 8–11 знаков.

  • Старый матч может быть недоступен: Valve удаляет реплеи примерно через неделю.
